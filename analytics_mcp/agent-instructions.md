# Reading Coach — agent instructions

The canonical system prompt lives in [`system-prompt.md`](system-prompt.md).
It is also served automatically as the MCP server's `instructions` field, so
MCP clients that honor server instructions pick it up with no setup.

For LibreChat: paste the full contents of `system-prompt.md` into the
**Instructions** field of the agent (Agents builder → Reading Coach →
Instructions).
